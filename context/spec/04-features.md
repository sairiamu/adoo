# 04 - Features (v1, manual only)

## Workspace
- Home: recent projects, new project from preset or template.
- Presets: Reel 1080x1920, Story 1080x1920, Ad 1080x1350 (4:5), Square 1080x1080, Landscape 1920x1080, Poster (custom size).
- Light/dark clay theme switch.

## Canvas Editor
- Add: text, shapes, images, video, icons.
- Select, multi-select, drag, resize, rotate, snap to guides and grid.
- Align and distribute, group/ungroup, lock, hide, duplicate.
- Layers panel with drag-to-reorder and rename.
- Properties panel for everything on an element (position, size, opacity, typography, fill, stroke, shadow, filters).
- Zoom, pan, safe-area overlays (Reels/Shorts UI safe zones).

## Timeline
- Scenes as top-level blocks; elements as clips inside a scene.
- Drag to move, drag edges to trim, split at playhead.
- Playhead scrubbing, play/pause, loop, frame stepping.
- Audio tracks with waveform display, volume, fade in/out.
- Keyframes for x, y, scale, rotation, opacity with easing.

## Animation
- In / out / loop presets: fade, slide, pop, zoom, blur-in, typewriter, bounce.
- Per-element delay, duration and easing.
- Scene transitions: fade, slide, zoom, wipe.
- Ken Burns on images.
- Manual text captions: add timed lines/words by hand, with styles (highlight, pop, karaoke).

## Media
- Video: trim, speed, volume, crop/fit, basic filters.
- Image: crop, fit, filters.
- Audio: trim, volume, fades.
- Library panel: grid of imported assets with search, tags and thumbnails.

## Brand Kit
- Colors, heading/body fonts, logo.
- Elements can bind to brand tokens; changing the kit updates all bound elements.

## Templates
- Save any project as a template.
- Start new projects from templates (starter reel and starter ad ship with the app).

## Project
- Autosave, undo/redo (unlimited per session), duplicate, rename, delete.
- Version snapshots (manual "save version").

## Keyboard Shortcuts
Space play/pause, Cmd/Ctrl+Z undo, Shift+Cmd/Ctrl+Z redo, Cmd/Ctrl+D duplicate, Delete remove, S split, arrows nudge, Shift+arrows nudge 10px, Cmd/Ctrl+S save version.

## Later (not in v1)
AI generation, auto captions, TTS, xyflow pipelines, batch/variant rendering, stock asset APIs, Lottie/Rive, 3D, cloud rendering.
